# 💻 Portfólio — Santhiago Sampaio

Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades, projetos e experiências na área de tecnologia e design.

## 👨‍💻 Sobre o projeto

Este projeto foi desenvolvido como parte das atividades acadêmicas de Engenharia de Software, com o objetivo de aplicar conceitos de desenvolvimento web, estruturação de páginas, responsividade e experiência do usuário.

O portfólio apresenta:

- 🏠 Página inicial
- 👨‍💻 Sobre mim
- 🚀 Projetos
- 💼 Experiências
- 📩 Formulário de contato
- 🔗 Links para redes profissionais

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Figma
- Git
- GitHub

## 🎨 Design

O projeto foi desenvolvido seguindo uma proposta visual moderna e minimalista, utilizando:

- Layout responsivo
- Design Mobile First
- Paleta de cores em preto, branco e roxo
- Tipografia simples e objetiva
- Seções organizadas para facilitar a navegação
- Componentes adaptáveis para diferentes tamanhos de tela

## 📱 Responsividade

O portfólio foi desenvolvido para funcionar em diferentes dispositivos:

- 💻 Desktop
- 📱 Smartphone
- 📟 Tablet

O layout se adapta automaticamente de acordo com o tamanho da tela.
